4. Copy the key

Use the copy button next to your new key. It's a long line of letters and numbers.

lock key

5. Keep it private

  • Treat it like a password. Anyone who has it can use your Gemini quota.
  • Save it somewhere private, such as a password manager.
  • Never post it online or share it in chats, screenshots or code.
  • If it ever leaks, delete it in AI Studio and create a new one.
  • The free tier is enough for this app, so you don't need to set up billing. With billing on, usage can cost money.
