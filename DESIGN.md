## Brand & Style

This design system establishes an experimental sci-fi acoustic workstation environment engineered for real-time multilingual translation, live voice synthesis, and real-time meeting intelligence. The aesthetic merges precision studio telemetry with deep-space operational interfaces, balancing sterile analytical clarity with fluid acoustic warmth.

### Aesthetic Foundation
- **Experimental Sci-Fi Console**: High-density data readouts, real-time waveform monitors, and spectral analyzers coexist within hyper-refined pill silhouettes.
- **Radiant Chromatic Resonance**: High-energy spectral violet and electric cyan emanations penetrate deep obsidian canvas depths, creating directional lighting cues that simulate physical audio hardware emitting coherent photonic signals.
- **Glass Acoustic Housing**: Precision panels with layered refractive blurs, whisper-weight optical borders, and zero-gravity depth hierarchies.

## Colors

The palette simulates optical emission inside an ultra-low-reflection acoustic chamber. All light originates from live system telemetry and resonant signals rather than ambient surface illumination.

### Spectrum Allocation
- **Canvas Base (`#0b0f19`)**: Ground-zero abyss. Absorbs ambient light and provides infinite contrast for luminous waveforms.
- **Sub-Surface Canvas (`#0f172a`)**: Structural framing, modular bays, and secondary deck containers.
- **Primary Spectral Violet (`#8b5cf6`)**: Active carrier signals, primary interaction triggers, active vocal channels, and focused state energy.
- **Secondary Electric Cyan (`#06b6d4`)**: Synthetic translation streams, incoming foreign signals, telemetry readouts, and temporal markers.
- **Tertiary Plasma Blue (`#38bdf8`)**: Live waveform peaks, active microphone sensitivity nodes, and connection integrity beacons.
- **Acoustic Translucencies**: Surface fills use graded opacities from `rgba(255, 255, 255, 0.03)` to `rgba(255, 255, 255, 0.07)`, held by fine optical boundaries of `rgba(255, 255, 255, 0.08)`.

## Typography

The typographic hierarchy pairs the aerodynamic geometry of Space Grotesk with the computational rigor of Space Mono. 

- **Space Grotesk**: Reserved for session titles, speaker attributions, major mode triggers, and high-impact metrics. Characterized by wide proportions, deep cuts, and rhythmic forward inertia.
- **Space Mono**: Powers continuous transcription dialogues, timestamp sequences, bit-rate indicators, real-time decibel counters, and telemetry readouts. Its fixed-width cadence guarantees structural visual stability during rapid numeric flux.
- **Casing Rules**: All operational status chips, table telemetry headers, and studio toggles are enforced in strict uppercase with expanded tracking (`0.06em` to `0.1em`).

## Layout & Spacing

The workstation layout runs on a responsive 12-column adaptive fluid grid engineered for real-time monitoring and parallel translation streams.

### Layout Architecture
- **Desktop (1280px+)**: Tri-pane command deck. Left column (3 spans) houses session configurations, audio I/O matrices, and speaker identification tiers. Center stage (6 spans) presents real-time multi-track translation cascades and oscillating spectral visualizers. Right column (3 spans) handles the live meeting summary ledger and contextual action trackers.
- **Tablet (768px - 1279px)**: Dual-pane interface with collapsible monitoring modules using 8 fluid columns.
- **Mobile (< 768px)**: Single continuous stream on a 4-column layout. Studio controls compress into a persistent floating pill dock moored along the lower optical threshold.

### Rhythmic Density
Layout spaces adhere strictly to an 8px base rhythm (`0.5rem`). Micro-telemetry groupings utilize tighter 4px gaps (`0.25rem`) to maintain informational unity among paired values (e.g., latency timers paired with signal indicators).

## Elevation & Depth

Elevation is rendered through photonic luminescence and refractive glass stacking rather than conventional diffuse drop shadows.

### Atmospheric Stacking
- **Deck Zero (Canvas)**: Solid deep obsidian (`#0b0f19`). The baseline canvas for all dynamic events.
- **Layer 1 (Recessed Bays)**: Dark glass (`#0f172a` at 60% opacity, `backdrop-filter: blur(16px)`). Bound by `1px solid rgba(255, 255, 255, 0.05)`. Serves as secondary wells for transcripts and peripheral telemetry.
- **Layer 2 (Floating Consoles)**: Refractive shields (`rgba(15, 23, 42, 0.75)`, `backdrop-filter: blur(24px)`). Outlined by `1px solid rgba(255, 255, 255, 0.12)`.
- **Layer 3 (Modals & Overlays)**: Suspended glass prisms (`rgba(11, 15, 25, 0.85)`, `backdrop-filter: blur(32px)`) with top-edge highlighted strokes (`1px solid rgba(139, 92, 246, 0.4)`).

### Spectral Resonance Glows
Active nodes, live frequency bars, and primary interactive elements project layered radial glows:
- **Quiescent**: No glow; crisp ghost borders.
- **Streaming Violet**: `box-shadow: 0 0 24px -4px rgba(139, 92, 246, 0.45), 0 0 8px 0px rgba(139, 92, 246, 0.3)`.
- **Synthesis Cyan**: `box-shadow: 0 0 24px -4px rgba(6, 182, 212, 0.45), 0 0 8px 0px rgba(6, 182, 212, 0.3)`.

## Shapes

The design system employs continuous curved pill architecture (Level 3 Roundedness), creating an aerodynamic counterpoint to rigorous technical data tables.

### Geometry Specifications
- **Interactive Controls & Badges**: Fully rounded circular caps (`border-radius: 9999px` / `1rem` base).
- **Console Panels & Containers**: Large sweeping rounded chambers (`border-radius: 2rem` via `rounded-lg`).
- **Telemetry Shells & Overlays**: Ultra-curved display hulls (`border-radius: 3rem` via `rounded-xl`).
- **Data Cells & Inline Inputs**: Capsule profiles providing physical grip affordance within virtual coordinates.

## Components

### Buttons & Transport Triggers
- **Primary Carrier Action**: Full-pill button with a radiant gradient from `#8b5cf6` to `#6366f1`. Text rendered in Space Grotesk Bold. Resting outer aura of `rgba(139, 92, 246, 0.3)`. On hover, luminance elevates to 100% with a secondary inner border reflection (`inset 0 1px 1px rgba(255, 255, 255, 0.4)`).
- **Secondary Studio Control**: Refractive dark-tinted pill (`rgba(255, 255, 255, 0.05)`) with an outer boundary of `rgba(255, 255, 255, 0.12)`. Space Mono medium label. On hover, boundary flashes electric cyan (`#06b6d4`).
- **Destructive/Mute Switch**: Deep vermilion pill base with crimson spectral ring glow on engagement.

### Spectral Pill Chips & Status Badges
- **Live Stream Pill**: 24px height, Space Mono uppercase label (`10px`). Encased in dark translucent violet (`rgba(139, 92, 246, 0.15)`) with a bounding ring of `rgba(139, 92, 246, 0.4)`. Contains a pulsing 6px radiant cyan LED dot.
- **Language Channel Indicator**: Dual-segment pill badge. Left segment displays source language (e.g., `JA-JP`) over opaque slate; right segment displays target translation (e.g., `EN-US`) filled with luminous violet.

### Real-Time Live Audio Visualizer
- Oscillating 32-bar or 64-bar frequency array housed within a pill frame.
- Bars animate vertically using continuous cubic-bezier transforms. Low frequencies cast deep violet tones, graduating up into bright cyan and white at audio peaks.
- Outer glass boundaries reflect active waveform amplitudes dynamically.

### Transcript Dialogue Lists
- Chronological bubble capsules suspended in Layer 1 bay containers.
- **Source Bubble**: Left-aligned, dark glass fill with a subtle cyan left-edge accent stroke (`2px solid #06b6d4`).
- **Synthesized Voice Bubble**: Right-aligned, dark glass fill with an active violet right-edge accent stroke (`2px solid #8b5cf6`).
- Space Mono micro-telemetry (timestamp, confidence index, speaker tag) pinned along the capsule perimeter.

### Input Fields & Search Vectors
- Fully radiused pill inputs with deep obsidian fills (`#0b0f19`) nested within Layer 2 bays.
- Placeholder text set in low-opacity Space Mono (`rgba(255, 255, 255, 0.3)`).
- Focus state triggers an immediate electric cyan perimeter illumination (`0 0 0 1px #06b6d4`) paired with an external `12px` ambient halo.

### Checkboxes, Radios, and Rotary Knobs
- **Toggles**: Pill switches. The track features a sunken matte slot; the sliding thumb is a gleaming white-violet sphere projecting a soft directional drop glow.
- **Dial Knobs**: Virtual concentric studio potentiometers with an arc track showing violet signal gain, paired with numeric decibel readings in Space Mono at the center.
